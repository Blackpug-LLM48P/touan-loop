# test-prep-print（プリント作成）

親が印刷して子どもに渡す、A4のプリントを作る。

## 入力

次のどちらか。

- **テスト前**：テスト範囲（範囲表の写真や文字、教科書の章名）
- **テスト後**：`answer-sheet-review` が作った `analysis.json`

子どものデータは `data/` に置く（このフォルダは push されない）。

## 手順

1. 入力を読み、何を練習させるプリントかを一文で決めて親に伝える。
2. `print.json` を作る（形は下）。
3. PDFを作る。
   ```
   python3 skills/test-prep-print/scripts/build_print.py data/print.json out/print.pdf
   ```
4. できたPDFを画像にして全ページを見る。文字の欠け、はみ出し、マス目の字数を確かめる。
5. 親に渡す。問題ごとに「何を練習する問題か」を一行で添える。

## プリントの決まり

- 並びは固定：**傾向の解説 → 対策 → 問題 → 解答と解説**。解答は新しいページから（切り離して渡せる）。
- 記述問題には字数ぶんのマス目を付ける。模範解答はその字数以内にする。
- 傾向と対策は、子どもが読む文で書く。1項目は2行まで。
- 問題文は教科書や問題集を写さない。数値や場面は自分で作る。
- 計算問題は、解答を別の方法で検算してから載せる。
- テスト後のプリントでは、`cause.status` が `confirmed` の原因だけを出題の根拠にする。`hypothesis` と `unknown` は「親に確かめてほしい点」として別に伝える。
- 白黒印刷で読めること。色で区別しない。

## print.json の形

```json
{
  "title": "理科　復習プリント（密度）",
  "subject": "理科",
  "scope": "身のまわりの物質",
  "trend": ["計算はできているが、単位の書き忘れで失点している。"],
  "strategy": ["答えを書いたら、最後に単位を指でさして確かめる。"],
  "questions": [
    {"id": "1", "type": "short", "text": "…", "answer": "…", "explanation": "…"},
    {"id": "2", "type": "essay", "chars": 25, "text": "…", "answer": "…", "explanation": "…"}
  ]
}
```

- `type`：`short`（答え欄）／`essay`（マス目。`chars` が必要）
- スクリプトは、項目の欠け・問題番号の重なり・模範解答の字数オーバーを見つけると、PDFを作らずに止まる。

## フォント

IPAゴシック（`ipagp.ttf` と `ipag.ttf`）を使う。見つからないときはスクリプトが止まるので、READMEの手順で `fonts/` に置く。別のフォントで代用しない。

## してはいけないこと

- 子どもの氏名・クラス・番号・学校名をプリントやファイル名に入れない。
- 答案の写真や `data/` の中身をコミットしない。
- 確かめていない答えを載せない。確かめられなかったら、その問題は外して親に伝える。
